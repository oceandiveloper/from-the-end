# Tracks

Scripts for Kevin's own tracks (and later the public formats). Kevin tests every format on himself first.

## Formats

| Format | Length | When | Structure |
|---|---|---|---|
| Evening "Fall asleep in the end" | ~20–25 min | before sleep | Landing → Revision (changes with the day: Work / Family / Money / Calm) → Scene (one wish, stays for weeks) → Drift (no outro, ambient fades) |
| Morning "Wake up in the end" | ~15 min | after getting up, during the routine (coffee, teeth, shower) | v2: continuous talk with short calls back to the present; Up → First minutes → Coffee → Body (line 6) → Mirror → From the end (inner conversation tonight) → Trust (line 9) → Work (line 1, one word for the day) → Out the door |
| Midday Reset | ~7.5 min | after hours at the screen, head buzzing | v2: Step away → Eyes (far away) → Breath (long out) → Body → Sound → Closing the tabs → Your energy → Back (ends awake) |
| Padel Before | ~5 min | before a match, nerves | Arrive → Breath → The nerves (energy, not enemy) → From the end (walking off court) → Three lines → Go |
| Padel After | ~6–8 min | after a rough game, inner critic loud | Kevin (v3, Neville language): Catch → What the replay does → Revision (narrated through sound and feel) → Three lines → Something that went right → Done. Public (Calm v1): just talk, no LoA, from "I failed" to "today is done, next time I try again" |

Evening tracks are built from modules: Landing and Drift are reused, the Revision is chosen per night, the Scene stays the same for weeks. Every module is voiced once; assembling a track costs no credits.

## Script conventions

- `## N. Name` starts a module. `[pause Xs]` on its own line = silence. Blank line = new voice segment.
- English only. Always "you" (never "he"/"she"): gender-neutral, so every track can be tested with anyone. Revisions: the old moment is seen from outside, the new version is lived from inside ("step into it").
- **Flow over silence (Kevin, 2026-11-09):** the mind is spinning when a track starts, silence doesn't catch it, a voice does. Talk continuously, like the YouTube voices Kevin likes: imagery, repetition, guiding the attention. Pauses only where the listener actually does something: a breath (5–6 s), seeing a scene (8–15 s), repeating a line (8 s). No pause after a plain statement. Awake tracks ≤ 15 % silence, evening ≤ 30 % until the Drift.
- **The voice tells the scene, the listener doesn't build it (Kevin, 2026-11-10):** never "pick a moment" + long silence + "now change it and live it". That doesn't pick Kevin up at all. Instead the voice narrates both versions itself, in concrete detail (old version briefly from outside, new version from inside, step by step), and may repeat the new version once more, a bit slower. The listener just follows. No pause longer than ~6 s anywhere except the evening Drift. All v1 tracks (Midday, Padel Before, evening Revisions/Scene) still use the old pattern and get rewritten in the rollout.
- **No pictures (2026-11-10):** Kevin can barely visualize (only short still frames, hypnosis never worked). Scenes run through sound, touch, body and dialogue: the clean pop off the racket, a sentence someone says to you, the weight of the laptop as you close it, your own voice saying something (Neville: feeling is the secret, inner conversation, handshake). Never "see it / picture / watch it like a film / let it play again". The channel niche is LoA for people who can't visualize, so this applies to public tracks too.
- No meditation instructions in tracks for other people (Kevin, 2026-11-10): no "close your eyes", no breathing commands. Just talk that picks people up, calms them and shifts the perspective. Kevin's own versions may keep a breath now and then.
- One paragraph = one voice segment, several sentences long, so ElevenLabs keeps the natural rhythm. The mixer trims each segment's silence and joins segments without a pause marker with a short breath gap (0.6 s).
- Identity lines from `docs/kevin-2.0.md`, at most three occurrences per track, no amounts, no promises, no claimed feelings.

## Production (current, v1)

1. Parse the script into segments: `python3 scripts/parse_track.py docs/tracks/<track>.md build/plan.json`.
2. POST the segments to WF8 `fte-tracks-voice-segments` → Bunny `tracks/{trackId}/{key}.mp3`. **At most 4 segments per call, one call at a time**: ElevenLabs allows 5 parallel requests, WF8 doesn't wait between batches, and if one request fails the whole run uploads nothing (credits are still spent). Wait until the chunk's files are on the CDN before sending the next one. Never HEAD-check CDN URLs without a query string before they exist (Bunny caches the 404); the mixer adds `?fresh=` for that reason.
3. Mix locally with `scripts/make_ambient.sh` (once) and `python3 scripts/mix_track.py build/plan.json <trackId> "<Title>" <tailSeconds> <fadeSeconds>`: segments + silences, loudnorm −20 LUFS, ambient underneath (brown noise + slow A/E/A drone, generated by ffmpeg, ~18 dB below the voice), mono 96 kbps (Telegram limit 20 MB).
4. The mixer writes two files: `<name>-voice.mp3` (voice only, what the bot plays) and `<name>.mp3` (with background). Upload with WF9 `fte-upload-audio`, create a Personal Tracks record (Status "Audio Ready"). The bot then lists it under `/tracks`.

Evening variants are pre-mixed (one MP3 per Revision: Work / Family / Money / Calm), so the bot only picks a file. No mixer on the server needed. Revision drafts for Work, Family, Calm: `evening-revisions-v1.md`.

In the bot (WF0, node "Route Update"): `/morning` and `/reset` play directly (map `DAILY`). `/evening` ("How was today?" → Work / Family / Money / Calm) and `/padel` (Before / After) show buttons (map `MENUS`; the buttons themselves live in the Telegram nodes "Ask Evening" and "Ask Padel", labels and callback_data `m:<menu>:<key>` must match). `/tracks` lists everything, `/help` shows the commands. Update URLs there when a new version is published.

## Audio versions and background

- Every track exists as **voice only** (`-voice.mp3`) and **with background**. The bot plays voice only (Kevin, 2026-11-09: the generated ffmpeg ambient doesn't work for him).
- The app later mixes voice + a background the listener picks (or none) at playback. So the voice-only file is the master; background tracks are separate loops, not baked in.
- The current background (`scripts/make_ambient.sh`, brown noise + drone) is a placeholder.

## Background tracks (Airtable "Background Tracks" `tblmKXp82bw4Ncxt1`)

One row per loop: Name, Status (Idea / Generated / Approved / Rejected), **Usage Rights**, Generator, License, Model, Prompt, Seed, Kind, Use For, Loop Seconds, Audio URL, Kevin (rating), Feedback. The app later lists only rows with Status "Approved" **and** Usage Rights "Public OK"; Kevin's private player may use everything.

| Source | Cost | Usage Rights | Note |
|---|---|---|---|
| ElevenLabs Music (existing subscription) | credits | Public OK once the plan is confirmed (paid plans allow commercial use, except film/TV/games) | AI, prompt-based, best route for the app |
| Envato Elements (subscription) | included | YouTube only | register per project; app use unclear, ask Envato support before the app ships |
| Uppbeat (subscription) | included | YouTube only | licence is for video content; apps need a custom licence |
| MusicGen local (`scripts/gen_background.py`) | free | **Private only** | weights CC-BY-NC 4.0; ~40 s per 30 s loop on the M1 Max |

ElevenLabs Music: WF14 **Generate Background** (`07nWaUGUcYjxVKH0`), webhook `fte-backgrounds-generate` `{name, prompt, seconds 30–180, kind, useFor, model?}` → instrumental track (`music_v2_5`) → Bunny `backgrounds/{name}.mp3` → Airtable row (Usage Rights "Check"). `seed` cannot be combined with `prompt` (API 422). The API key needs the permission **Music Generation**. Batch: `scripts/gen_backgrounds_elevenlabs.sh docs/tracks/backgrounds-v1.json` (one at a time, waits for the CDN). The tracks are not seamless loops: the player crossfades at the end (~4 s).

MusicGen: `.venv-audio/bin/python scripts/gen_background.py <name> "<prompt>" --seed 1 --seconds 30 [--model facebook/musicgen-medium]` → `build/backgrounds/<name>-loop.mp3` (seamless loop, 4 s crossfade at the seam, the player repeats it). One-time setup: `python3 -m venv .venv-audio && .venv-audio/bin/pip install torch transformers scipy accelerate`. Upload: WF9 with `path=backgrounds/<name>.mp3`.
