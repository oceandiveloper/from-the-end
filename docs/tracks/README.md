# Tracks

Scripts for Kevin's own tracks (and later the public formats). Kevin tests every format on himself first.

## Formats

| Format | Length | When | Structure |
|---|---|---|---|
| Evening "Fall asleep in the end" | ~20–25 min | before sleep | Landing → Revision (changes with the day: Work / Family / Money / Calm) → Scene (one wish, stays for weeks) → Drift (no outro, ambient fades) |
| Morning "Wake up in the end" | 10–15 min | after waking, before the phone | Before → Arrive → three Level-100 lines from `docs/kevin-2.0.md` (each once, long silence after) → Carry it (one word) → Rise. v1 uses statements 1, 6, 9; daily rotation planned |
| Midday Reset | ~7 min | when everything is too much | Stop → Breath → Weather → Anchor → Return (ends awake) |
| Padel Before | ~5 min | before a match, nerves | Arrive → Breath → The nerves (energy, not enemy) → From the end (walking off court) → Three lines → Go |
| Padel After | ~7 min | after a rough game, inner critic loud | Stop → The voice (weather) → One point (revision, from inside) → Three lines → Keep one good thing → Return |

Evening tracks are built from modules: Landing and Drift are reused, the Revision is chosen per night, the Scene stays the same for weeks. Every module is voiced once; assembling a track costs no credits.

## Script conventions

- `## N. Name` starts a module. `[pause Xs]` on its own line = silence. Blank line = new voice segment.
- English only. Always "you" (never "he"/"she"): gender-neutral, so every track can be tested with anyone. Revisions: the old moment is seen from outside, the new version is lived from inside ("step into it").
- **Flow over silence (Kevin, 2026-11-09):** the mind is spinning when a track starts, silence doesn't catch it, a voice does. Talk continuously, like the YouTube voices Kevin likes: imagery, repetition, guiding the attention. Pauses only where the listener actually does something: a breath (5–6 s), seeing a scene (8–15 s), repeating a line (8 s). No pause after a plain statement. Awake tracks ≤ 15 % silence, evening ≤ 30 % until the Drift.
- One paragraph = one voice segment, several sentences long, so ElevenLabs keeps the natural rhythm. The mixer trims each segment's silence and joins segments without a pause marker with a short breath gap (0.6 s).
- Identity lines from `docs/kevin-2.0.md`, at most three occurrences per track, no amounts, no promises, no claimed feelings.

## Production (current, v1)

1. Parse the script into segments: `python3 scripts/parse_track.py docs/tracks/<track>.md build/plan.json`.
2. POST the segments to WF8 `fte-tracks-voice-segments` → Bunny `tracks/{trackId}/{key}.mp3`.
3. Mix locally with `scripts/make_ambient.sh` (once) and `python3 scripts/mix_track.py build/plan.json <trackId> "<Title>" <tailSeconds> <fadeSeconds>`: segments + silences, loudnorm −20 LUFS, ambient underneath (brown noise + slow A/E/A drone, generated by ffmpeg, ~18 dB below the voice), mono 96 kbps (Telegram limit 20 MB).
4. Upload with WF9 `fte-upload-audio`, create a Personal Tracks record (Status "Audio Ready"). The bot then lists it under `/tracks`.

Evening variants are pre-mixed (one MP3 per Revision: Work / Family / Money / Calm), so the bot only picks a file. No mixer on the server needed. Revision drafts for Work, Family, Calm: `evening-revisions-v1.md`.

In the bot (WF0, node "Route Update"): `/morning` and `/reset` play directly (map `DAILY`). `/evening` ("How was today?" → Work / Family / Money / Calm) and `/padel` (Before / After) show buttons (map `MENUS`; the buttons themselves live in the Telegram nodes "Ask Evening" and "Ask Padel", labels and callback_data `m:<menu>:<key>` must match). `/tracks` lists everything, `/help` shows the commands. Update URLs there when a new version is published.
